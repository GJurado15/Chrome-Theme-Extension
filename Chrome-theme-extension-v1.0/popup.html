Chrome Theme Generator

Generates a theme manifest.json. Chrome themes must be loaded manually.

How to apply your theme in Chrome:
  1. Create a folder (example: my-theme).
  2. Put the downloaded manifest.json inside that folder.
  3. Open chrome://extensions.
  4. Enable Developer mode (top-right toggle).
  5. Click Load unpacked and select your theme folder.
Note: Chrome themes must be loaded manually due to browser security restrictions.
