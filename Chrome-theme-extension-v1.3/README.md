# Chrome Theme Generator

## Getting the Code
To get a copy of this repository on your device, clone it with Git:
```
git clone https://github.com/GJurado15/The-Real-Group-0100.git
```

Alternatively, you can download the repository as a ZIP file directly from GitHub and extract it to a folder of your choice.

## Installing and Using the Extension in Chrome

Google Chrome allows you to load extensions that are stored in a folder on your computer. This is known as loading an "unpacked" extension.

### 1. Access the Extensions Page
- Open your Google Chrome browser.
- Navigate to `chrome://extensions/`
- Alternatively, click the three vertical dots in the top-right corner, select **Extensions**, and then click **Manage Extensions**.

### 2. Enable Developer Mode
- In the top-right corner of the Extensions page, locate the toggle switch for **Developer mode**.
- Ensure the toggle is switched to the **On** position.

### 3. Load the Unpacked Extension
- Once Developer mode is enabled, a new bar will appear with three buttons. Click **Load unpacked**.
- A file browser window will open. Select the folder titled `Chrome-theme-extension-v1.3`.

### 4. Create and Download Themes Using the Extension
- Open the theme generator by clicking the **Theme Generator** extension icon in your toolbar.
- Optionally select a **preset theme** (Dark Mode, Ocean Breeze, Sunset Glow, Forest, or Monochrome) as a starting point.
- Customize your theme:
  - Choose a **background type**: Solid Color, Gradient, or Image Upload.
  - For gradients, pick a **direction** and add up to 6 **color stops**.
  - Set **frame**, **toolbar**, **active tab**, **inactive tab**, and **text** colors.
- Watch the **live preview** at the top of the popup update in real-time.
- Click **Download Theme** to download a `manifest.json` (solid color) or `theme.zip` (gradient/image).

### 5. Load the Generated Theme
- Return to `chrome://extensions` and click **Load unpacked**.
- Navigate to the folder where you saved and unzipped the generated theme file.
- Select the folder and click **Open** or **Select Folder**.
- Chrome will immediately apply the theme to your browser.

### 6. Additional Features
- **Export Config**: Save your current settings as a JSON file to share with others.
- **Import Config**: Load a shared JSON config to apply someone else's theme settings.
- **Saved Themes**: Your last 10 themes are automatically saved. Click the **Saved Themes** section to load or delete previous themes.
- **Reset**: Click the **Reset** button to return all settings to their defaults.
